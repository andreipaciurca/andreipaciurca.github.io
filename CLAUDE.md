# Architecture Overview

- **Core Engine**: Modular JS implementation using ES Modules, located in `/js/`.
- **Data Pipeline**:
    - Trigger: GitHub Actions (`push` to master or monthly cron).
    - Fetcher: Apify LinkedIn Scraper → `data/linkedin.json`.
    - Intelligence: Google Gemini 2.0 Flash (`gemini-2.0-flash`).
    - Output: `profile-data.js` (Single Source of Truth).
- **UI System**: Vanilla CSS with theme-driven CSS variables (`.light-mode`).
- **Verification**: Jest-based integration tests in `tests/resume.spec.js`.

## Implementation Details

- **Module Orchestration**: `js/main.js` bootstraps the application and wires all event listeners.
- **AI Integration**: `scripts/update-resume.js` uses `@google/generative-ai` with the stable `gemini-2.0-flash` model to summarize LinkedIn experience text into professional prose.
- **State Management**: Encapsulated in `js/modules/state.js` — tracks language, animation frames, translation cache, and timeouts.
- **Print Optimization**: `js/modules/print.js` generates an ATS-friendly single-page layout with a heuristic quality score (0–100).
- **Translation**: `js/modules/translation.js` calls the MyMemory API with `encodeURIComponent` (not `encodeeURIComponent`) — the extra-e typo is a known past bug, now fixed.

## Key Files

| File | Role |
|------|------|
| `profile-data.js` | All content (auto-generated by pipeline, do not edit manually unless re-running pipeline) |
| `js/modules/dom.js` | All 67 DOM element references — must stay in sync with `index.html` IDs |
| `js/modules/config.js` | UI text constants, translation config, print config |
| `i18n-data.js` | Romanian translation dictionary |
| `health.json` | Pipeline run status: `{ status, timestamp, gemini, apify }` |
