# Terminal Resume Site

## Features
- **Auto-Update**: Synchronizes profile data with LinkedIn via Apify + Gemini AI summarization.
- **Light/Dark Mode**: Adaptive themes for optimal reading.
- **Terminal UI**: Interactive headline with command support (`help`, `theme`, etc.).
- **ATS-Friendly**: Optimized printable PDF layout.

## Setup
1. **GitHub Secrets**: Add `APIFY_TOKEN` and `GEMINI_API_KEY`.
2. **Local Development**: Run `python3 -m http.server 8080`.
