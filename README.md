# Terminal Resume Site

## Features
- **Auto-Update**: Synchronizes profile data with LinkedIn via Apify + Gemini AI summarization.
- **Narrative Experience**: Work history is automatically transformed into high-impact professional summaries using Gemini 2.0.
- **Light/Dark Mode**: Adaptive themes for optimal reading.
- **Interactive Terminal**: Custom headline with integrated command-line interface.
- **ATS-Friendly**: Optimized printable layout.

## Setup
1. **GitHub Secrets**: Add `APIFY_TOKEN` and `GEMINI_API_KEY`.
2. **Local Development**: Use a local web server (e.g., `python3 -m http.server 8080`).
